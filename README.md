# FixPro GitHub Pages

Responsive Demo-Website für einen Allzweck-Reparaturservice.

## Enthalten
- index.html
- style.css
- script.js

## GitHub Pages
1. Neues Repository erstellen.
2. Alle drei Dateien hochladen.
3. **Settings → Pages**
4. **Deploy from a branch**
5. Branch `main`, Ordner `/ (root)` auswählen.
6. Speichern.

Vor dem Livegang Telefonnummer, E-Mail, Servicegebiet und Firmenname in `index.html` ersetzen.

Das Kontaktformular ist eine Demo und versendet noch keine echten E-Mails.
